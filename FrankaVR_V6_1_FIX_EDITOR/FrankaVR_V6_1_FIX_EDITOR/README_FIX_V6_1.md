# FrankaVR V6.1 - Fix Edit Mode

Corrige el error `Destroy may not be called from edit mode! Use DestroyImmediate instead.`

## Instalacion
1. Cerrar Unity.
2. Copiar `Assets/FrankaVR/V6` de este paquete sobre la misma carpeta del proyecto y aceptar reemplazar.
3. Abrir Unity y esperar compilacion.
4. Ejecutar `FrankaVR -> 7 - Instalar mejoras visuales + movimiento V6`.

No agrega clases nuevas ni duplica scripts: solo reemplaza los archivos V6 existentes.
